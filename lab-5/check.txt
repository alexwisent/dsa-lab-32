Чек-лист тестирования функции get_triangle_type
================================================

ПОЗИТИВНЫЕ ТЕСТЫ (валидные треугольники)
---------------------------------------

1. Равносторонний треугольник (equilateral)
   Вход: 5, 5, 5
   Ожидаемый результат: "equilateral"

2. Равносторонний с плавающими числами
   Вход: 2.5, 2.5, 2.5
   Ожидаемый результат: "equilateral"

3. Равносторонний — граничный случай (минимальные положительные)
   Вход: 0.1, 0.1, 0.1
   Ожидаемый результат: "equilateral"

4. Равнобедренный треугольник (isosceles) — два равных ребра
   Вход: 6, 6, 7
   Ожидаемый результат: "isosceles"

5. Равнобедренный (равны другие пары сторон)
   Вход: 5, 3, 5
   Ожидаемый результат: "isosceles"

6. Равнобедренный (равны третья пара)
   Вход: 3, 5, 5
   Ожидаемый результат: "isosceles"

7. Равнобедренный с плавающими числами
   Вход: 5.5, 5.5, 6.0
   Ожидаемый результат: "isosceles"

8. Разносторонний треугольник (nonequilateral)
   Вход: 3, 4, 5
   Ожидаемый результат: "nonequilateral"

9. Разносторонний с плавающими числами
   Вход: 1.5, 2.0, 2.5
   Ожидаемый результат: "nonequilateral"


НЕГАТИВНЫЕ ТЕСТЫ (должны выбрасывать IncorrectTriangleSides)
------------------------------------------------------------

1. Одна сторона равна нулю
    Вход: 0, 5, 5

2. Отрицательная сторона
    Вход: -3, 4, 5

3. Все стороны нулевые
    Вход: 0, 0, 0

4. Нарушение неравенства треугольника (1 + 2 = 3)
    Вход: 1, 2, 3

5. Нарушение неравенства (сумма двух меньше третьей)
    Вход: 1, 1, 3

6. Некорректные типы данных — строка
    Вход: "5", 4, 5

7. Некорректные типы данных — None
    Вход: 5, None, 5

8. Некорректные типы данных — список
    Вход: [1], 2, 3

9. Смешанный некорректный случай (отрицательное + не число)
    Вход: -1, "a", 0
